# EERLoss: A Novel Loss Function for Training Deep Biometric Models
Official repository for the paper: **"EERLoss: A Novel Loss Function for Training Deep Biometric Models. A Case Study in Keystroke Dynamics"**.


[![Status](https://img.shields.io/badge/Status-Under_Revision-orange)](https://signalprocessingsociety.org/publications-resources/ieee-transactions-information-forensics-and-security/ieee-transactions)

---

## About the Study

This repository contains the formulation and implementation of a novel loss function named EERLoss: a subdifferentiable, and arbitrarily accurate approximation of the EER metric, enabling direct end-to-end optimization.
